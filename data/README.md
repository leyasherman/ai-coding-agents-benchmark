# Titanic data

Download the [Titanic dataset](https://www.kaggle.com/datasets/yasserh/titanic-dataset) from its provider after reviewing the current terms. Place the original file at `data/Titanic-Dataset.csv`. Some run scripts expect `titanic.csv` or `titanic_clean.csv` in their working directory; inspect each input path and generate the cleaned file with its corresponding preprocessing script.

Raw and cleaned passenger records are excluded because redistribution permission was not supplied. Cleaning differences are part of the benchmark; do not substitute one agent’s cleaned data for another when comparing runs.
